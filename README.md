# Chirpy
Simple HTTP Server in Go


# General - This project allows you to
Creating Users
Deleting Users
Creating Chirps
Retrieiving Chirp(s)
Delete Chirp
Login with Bearer and Authorization Token and verify user for Chirps

# To run the docker image
docker-compose up --build

1. Use Create User endpoint
2. Login as User
3. Use auth token from the Login endpoint in the Create Chirp endpoint
